# 【MCJE】主流服务端介绍与选择

## 如何选择服务端

:::tip[提示]
By：Zengxiaopi、ideafox
+ 如果你的需求仅为使用 Bukkit 插件，则我建议你使用 Paper 服务端。
+ 如果你需要游玩生电且需要使用 Bukkit 插件，则我建议你使用 Leaves 服务端。
+ 如果你需要完整的生电玩法，则我建议你使用 Fabric 服务端。
+ 如果你需要游玩命令/数据包地图，则我建议你使用 Vanilla 服务端。
+ 如果你需要游玩 Forge 模组，且不需要任何插件，并且有最好的 Mod 兼容性 则我建议你使用 Forge 服务端。
+ 如果你需要游玩 1.12.2 的 Forge 模组，且需要 Bukkit 插件，并且有较好的兼容性，则我建议你使用 CatServer 的 1.12.2 版本。
+ 如果你需要游玩 高版本 的 Forge 模组，且需要 Bukkit 插件，则我建议你使用 Arclight 服务端。
+ 如果你需要游玩 Fabric 模组，则我建议你使用 Fabric 服务端。
:::

## 主流服务端的介绍

:::info[提示]
部分服务端或者服务端的版本**可能并不存在于 SFE4 中**。    
排序无任何含义（并不是越靠前越好）！
:::

:::tip[提醒]
+ 1.16.5 及更低的版本使用 Java 8（部分版本可能需要使用 Java 7 运行）
+ 1.17 ~ 1.20.4 使用 Java 17
+ 1.20.5 ~ 1.21.11 使用 Java 21
+ 26.1 及更高版本使用 Java 25

如果你使用的为模组端，那么部分 mod 可能对 Java 版本有特定的要求。
:::


### Vanilla

模组：不支持

插件：不支持

版本：全版本

介绍：   
Mojang 发布的官方原版服务端，没有任何附加功能，但是对于数据包和命令地图有完美的兼容性。

---

### Arclight

模组：支持 (Forge`1.14.4+`，Fabric`1.20.4+`，NeoForge`1.20.4+`)

插件：兼容

版本：1.14.4 ~ 最新版

介绍：    
通过 Mixin 实现插件加载的混合服务端，支持 Minecraft 1.14.4 及以上的版本，在 1.18+ 比其他混合端更稳定一些。    
1.20.2 及之前仅支持 Forge 加载器；    
1.20.4 及之后支持 Fabric，NeoForge，Forge 加载器（三选一）。    

其所支持的插件为 **BukkitAPI** 插件。

:::warning[编者有话说]
虽然说是更稳定一些，但依旧有兼容性问题，一般情况下不建议使用混合端。
:::

---

### CatServer

模组：支持 (Forge)

插件：兼容

版本：1.12.2 1.16.5 1.18.2

介绍：    
老牌胶水混合端，1.12.2 的版本的兼容性无可比拟，除了 SpongeForge。    
其所支持的插件为 **BukkitAPI** 插件。

:::warning[编者有话说]
由于兼容性问题，一般情况下不建议使用混合端。
:::

---

### CraftBukkit

模组：不支持

插件：支持

版本：全版本

介绍：    
究极老东西，MC 的第一代插件端，现已合并到 Spigot 继续开发。    
其所支持的插件为 **BukkitAPI** 插件。

**简幻欢不提供此服务端。**

---

### Fabric ⭐

模组：支持 (Fabric)

插件：不支持

版本：1.14 ~ 最新版

介绍：    
新一代轻量化 mod 加载器，也是少有的可以让快照版本加载 mod 的加载器。   
新起之秀，开生电就用 Fabric 吧。

---

### Folia

模组：不支持

插件：支持

版本：1.19.4 ~ 最新版

介绍：

Paper 团队的新作品，有多线程的优化，对于服务器级别的超多核 CPU 非常友好。   
坏处就是由于多线程优化导致稳定性与插件兼容性真的很差。   
其所支持的插件为 **PaperAPI** 插件。

:::danger[警告]

由于 Folia 采用了一套全新的任务调度系统，因此对传统插件的兼容性较差。    
多线程提供的优化需要服务器至少拥有**8**个以上(官方文档推荐至少**16**个)**物理核心**才有明显效果。   
核心数少于**8**会造成严重卡顿。

:::

---

### Forge ⭐

模组：支持 (Forge)

插件：不支持

版本：全版本

介绍：   
老牌 Mod 加载器，你玩过 Minecraft 就会知道 Forge。   
对于 Forge Mod 有最好的兼容性，当然不支持插件。

:::info[下一个 Forge？]
在 2023 年 7 月 12 日，Forge 的 Discord 被 cpw 重命名，用于新的项目：NeoForge。除了 LexManos，几乎所有 Minecraft Forge 团队成员都加入了 NeoForged 团队。   
目前，大部分使用 Forge 的 mod 已转向使用 NeoForge 作为模组加载器，1.21.1 及更高版本建议使用 NeoForge。
:::

---

### Leaves

模组：不支持

插件：支持

版本：1.19 ~ 最新版

介绍：

Leaves 是一个致力于修复被 Paper 和 Bukkit 等服务端破坏了的原版特性的 Paper 分支。和 Paper 相比，Leaves 拥有一些新功能和更多的性能改进。   
其所支持的插件为 **PaperAPI** 插件。

:::info[编者有话说]
新一代生电之友，恢复了被 Paper 破坏的原版特性，不仅可以使用 Bukkit 插件，而且原生支持某些特性，包括但不限于：
+ Carpet 协议支持
+ Appleskin，Xaero 的世界地图，Jade 等 mod 的协议支持
+ 内置假人功能
+ 内置的第三方登录验证服务器(Yggdrasil)功能

虽然有诸多特性与好处，但与 Fabric 端相比，依旧有一定差距，具体表现为：
+ 部分特性与原版不符（如活塞递推方案与原版稍有不同等）
+ 性能优化相对激进，甚至部分机器需在高 mspt 的情况下才能正常运作
+ ... ...

因此若您无法接受这些缺陷，推荐您使用 Fabric。

更多配置详情请去 [Leaves 文档](https://docs.leavesmc.org/zh_Hans/leaves/reference/configuration) 查看。
:::

---

### Leaf

模组：不支持

插件：支持

版本：1.19 ~ 最新版

介绍：   
Leaf 是一个专注于寻找性能优化，原版特性，稳定之间的平衡的 Paper 分支，为大型网络，密集和高承载量场景设计。   
其所支持的插件为 **PaperAPI** 插件。

简幻欢默认不提供此服务端。

:::info[编者有话说]
Leaf 为极致的性能而设计。其整合了 Purpur 的优化，在大部分情况下可以直接替代 Purpur 使用。
:::

### Mohist

模组：支持 (Forge)

插件：兼容

版本：`1.7.10` `1.12.2` `1.16.5` `1.18.2` `1.19.2` `1.19.4` `1.20.1` `1.20.2`

介绍：   
著名~~胶水~~混合端，提供 Mod 与插件的支持。   
其所支持的插件为 **BukkitAPI** 插件。

简幻欢默认不提供此服务端。

:::warning[编者有话说]
此服务端所有权、版权、源代码已被 MohistMC 组织出售至第三方。   
Mohist 是混合服务端选择的下下策，尽量避免使用。
:::

---

### NeoForge ⭐

模组：支持 (NeoForge)

插件：不支持

版本：1.20.1 ~ 最新版

介绍：   
NeoForge 是 Minecraft Forge 的分支。   
在 2023 年 7 月 12 日，Forge 的 Discord 被 cpw 重命名，用于新的项目：NeoForge。除了 LexManos，几乎所有 Minecraft Forge 团队成员都加入了 NeoForged 团队。   
目前，大部分使用 Forge 的 mod 已转向使用 NeoForge 作为加载器。

:::warning[提示]
+ NeoForge 1.20.1 与原 Forge 兼容。
+ NeoForge 1.20.2 (及更高版本)与原 Forge 已分离，需要已标明兼容 NeoForge 的模组。
:::

:::info[编者有话说]
关于为什么要分叉一个新的 NeoForge 出来，请看[这篇文章](https://bbs.mcmod.cn/thread-15546-1-1.html)。
:::

---

### Paper ⭐

模组：不支持

插件：支持

版本：1.7.10 ~ 最新版

介绍：   
Paper 是 Minecraft 的一个高性能、优化版的服务端，致力于提供更好的游戏性能和稳定性，它基于 Mojang 官方的代码，通过优化和改进，使得服务器能够更有效地运行和管理。   
自 MC1.21.4 起，Paper 已从 Spigot 硬分叉，具体内容可查看这篇文章：https://www.minebbs.com/threads/paper.32419/ 。   
其所支持的插件为 PaperAPI 插件。

:::info[编者有话说]
此服务端基于 Spigot 优化而来，修了非常多的生电特性，但是对开服小白很友好。如果你是个开服新手可以使用这个服务端。   
生电玩家乖乖去用 Fabric 吧（或者可以试试 Leaves）。
:::

---

### Spigot

模组：不支持

插件：支持

版本：1.4.6 ~ 最新版

介绍：   
Spigot 是 Minecraft 的一个流行的第三方服务端，它建立在 CraftBukkit 的基础上，提供了更好的性能优化、更丰富的插件支持和额外的功能。通过 Spigot，玩家可以利用各种插件来定制服务器，增强游戏体验，并且它以其稳定性和可定制性而受到广泛欢迎。   
其所支持的插件为 **BukkitAPI** 插件。

---

### SpongeForge

模组：支持

插件：支持

版本：`1.8~1.12.2` `1.16.5` `1.19.4` `1.20.6` `1.21.1` `1.21.3~1.21.11` `26.x`

介绍：   
SpongeForge 是基于 Minecraft Forge 的 Sponge 插件平台。它将 Sponge 的灵活性和功能与 Minecraft Forge 的模组化特性相结合，允许玩家在 Minecraft 服务器上同时使用 Sponge 的插件和 Forge 的模组。   
其所支持的插件为 **SpongeAPI** 插件。不支持常规的 BukkitAPI 系插件！   
Sponge 插件放入 `/mods` 文件夹即可。

:::info[编者有话说]
曾经是个放弃支持的项目，不过在 2024 年 3 月 23 日，SpongeForge 项目被重启了，并更新了 1.19.4 版本(Re-enable SF publishing，来自 changelog)。

对于插件和 Mod 混合端兼容性的最终答案，唯一缺点是用不了 Bukkit 系的插件。
:::

---

### SpongeNeo

模组：支持

插件：支持

版本：1.21.1 ~ 最新版

介绍：   
Sponge API 在 NeoForge 的实现，支持在 NeoForge 服务端安装使用 Sponge 插件。   
其所支持的插件为 **SpongeAPI** 插件。不支持常规的 BukkitAPI 系插件！   
Sponge 插件放入 `/mods` 文件夹即可。

简幻欢不提供此服务端。

---

### SpongeVanilla

模组：不支持

插件：支持

版本：1.8 ~ 最新版

介绍：   
SpongeVanilla 是基于原版 Minecraft 的服务端，提供了强大的插件 API 和可定制性，让玩家能够通过插件增强和扩展他们的 Minecraft 服务器体验。   
其所支持的插件为 **SpongeAPI** 插件。不支持常规的 BukkitAPI 系插件！

简幻欢不提供此服务端。

---

### Youer

模组：支持（NeoForge）

插件：兼容

版本：1.21.1

介绍：   
Mohist 团队新作。在 NeoForge 上提供部分 PaperAPI+BukkltAPI 插件支持。   
目前处于测试阶段。

简幻欢不提供此服务端。
