# 【MCJE】关闭生物破坏

想在服务器中开启防爆？（关闭生物破坏）

## 使用命令
打开服务器控制台>终端

![服务器控制台终端](/img/pages/ins-console-2.webp)

输入以下命令(可直接复制，游戏内使用ctrl+v粘贴，控制台输入请去掉斜杠)：

```text title="1.21.11(快照25w43a)前"
/gamerule mobGriefing false
```

```text title="1.21.11(快照25w44a)后"
/gamerule mob_griefing false
```

:::warning[警告]
TNT依然可以造成破坏。   
生电玩家不推荐开启，不然一些机器无法正常工作！
:::
