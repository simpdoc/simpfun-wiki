# 【MCJE】关闭飞行检测

在服务器起飞或者浮空的时候被误踢？那你就需要看这个！

---

## 关闭自带的飞行检测
:::warning[提示]

`server.properties`不支持热重载，请在关闭服务器的情况下对其进行修改。

:::

在服务器文件管理根目录找到`server.properties`文件并打开，在其中找到这一行:

```properties title="server.properties"
allow-flight=false
```

将其中的`false`改为`true`后保存，这样就关闭自带的~~答辩~~飞行检测了。
