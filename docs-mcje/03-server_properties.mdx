# 【MCJE】server.properties 详解

`server.properties`是 Minecraft 多人游戏服务器的核心配置文件，用于存储所有服务端设置。

:::info[文件编辑规范]

+ 行顺序可以任意调整，但文件结构（键值对格式）不可改变
+ 每行以 = 分隔：左侧为变量名（不可修改），右侧为变量值（可按规则编辑）
+ 以 # 开头的行为注释，添加、修改或删除注释行不会影响游戏运行
+ 保存对`server.properties`的修改后，必须重新启动服务器才能使更改生效。

:::

:::info[Tips]

+ 如果`server.properties`文件中缺少某些属性（例如因服务端版本更新引入了新属性，或文件尚未创建），服务器启动时会自动补全缺失的属性，并将其值设为默认值。
+ 尽管文件扩展名为`.properties`，它实际上是一个普通的 **UTF-8 编码文本文件**（在 1.20 前的编码格式为 ISO 8859-1），您可以使用任何文本编辑器进行编辑。

:::

## 常用配置项解析
:::info[提示]
true = 是，false = 否。所有值均以行内代码框标出，示例：`false`
:::

### allow-flight
作用：

是否允许玩家飞行。

默认值：`false`

允许值：`false` `true`

:::info[提示]

此项配置在特定场景下（如服务端加载 Mod、网络延迟波动、命令方块高频传送实体等）存在误判风险，可能导致玩家被异常踢出。建议将该配置项设为`true`，以禁用此判定机制。

:::

### allow-nether
作用：

是否启用下界维度，关闭后，下界维度将不会生成，且玩家无法进入。

默认值：`true`

允许值：`false` `true`

:::warning[提示]

此项配置在 1.21.9 的快照 25w35a 后失效，使用游戏规则 `[allow_entering_nether_using_portals](https://zh.minecraft.wiki/w/%E6%B8%B8%E6%88%8F%E8%A7%84%E5%88%99/allowEnteringNetherUsingPortals)` 替代。

:::

### broadcast-console-to-ops
作用：

向所有在线 OP 发送所执行命令的输出（包括其他 OP 和控制台执行的命令）。

默认值：`true`

允许值：`false` `true`

### difficulty
作用：

控制游戏的默认难度。

默认值：`easy`

允许值：

+ `peaceful`/`0` （和平）
+ `easy`/`1` （简单）
+ `normal`/`2` （普通）
+ `hard`/`3` （困难）

如果设置了旧的数字 ID，则会自动转化为英文的难度名称。

:::info[提示]

该配置项的生效逻辑如下：

+ 服务器启动时，此项配置将覆盖存档中已设置的难度
+ 游戏内使用 `/difficulty` 命令修改难度仅对本次运行阶段生效
+ 服务器下次启动时，难度将重新被本配置覆盖，恢复为配置文件中设定的值

:::

### enable-command-block
作用：

是否允许命令方块运行。设置为 `false` 时，命令方块将不会执行命令。

默认值：`false`

允许值：`false` `true`

:::warning[提示]

此项配置在 1.21.9 的快照 25w35a 后失效，使用游戏规则 `[command_blocks_work](https://zh.minecraft.wiki/w/%E6%B8%B8%E6%88%8F%E8%A7%84%E5%88%99/commandBlocksEnabled)` 替代。

:::

### enable-rcon
作用：

是否允许远程连接服务器控制台。

默认值：`false`

允许值：`false` `true`

:::warning[警告]

由于 RCON 协议传输数据时没有加密，所以不建议把 RCON 端口暴露在互联网上！

RCON 客户端和服务端交换的所有数据（包括 RCON 密码）都会泄露给正在监听此连接的人！

:::

### enable-status
作用：

使服务器在服务器列表中看起来是“在线”的。如果关闭此项则不会显示在线，但可以正常连入。

默认值：`true`

允许值：`false` `true`

### enforce-secure-profile
作用：

要求玩家必须具有Mojang签名的公钥才能进入服务器。启用此选项也会阻止玩家发送未签名的[聊天](https://zh.minecraft.wiki/w/%E8%81%8A%E5%A4%A9)消息。

+ `true` - 不具有Mojang签名的公钥的玩家不能进入服务器。
+ `false` - 不具有Mojang签名的公钥的玩家也可进入服务器。

默认值：`true`

允许值：`false` `true`

### enforce-whitelist
作用：

在服务器上强制执行白名单。当启用后，不在白名单（前提是启用）中的用户将在服务器重新加载白名单文件后从服务器踢出。

默认值：`false`

允许值：`false` `true`

### force-gamemode
作用：

是否强制玩家加入时的游戏模式设置为默认的游戏模式。

+ `true` - 玩家总是以默认的游戏模式加入服务器
+ `false` - 玩家将以上次退出服务器时的游戏模式加入服务器

默认值：`false`

允许值：`false` `true`

### gamemode
作用：

设置默认的游戏模式。

默认值：`survival`

允许值：

+ `survival`/`0` （生存模式）
+ `creative`/`1` （创造模式）
+ `adventure`/`2` （冒险模式）
+ `spectator`/`3` （旁观模式）

如果设置了旧的数字 ID，则会自动转化为英文的游戏模式名称。

### generate-structures
作用：

是否允许新生成的区块中生成[结构](https://zh.minecraft.wiki/w/%E7%BB%93%E6%9E%84)。

默认值：`true`

允许值：`false` `true`

:::info[冷知识]

部分自然生成的建筑物在技术分类上属于[**地物**](https://zh.minecraft.wiki/w/%E5%9C%B0%E7%89%A9)，因此关闭此配置项后仍会正常生成，典型的例子包括[刷怪房（旧称地牢）](https://zh.minecraft.wiki/w/%E5%88%B7%E6%80%AA%E6%88%BF)和[沙漠水井](https://zh.minecraft.wiki/w/%E6%B2%99%E6%BC%A0%E6%B0%B4%E4%BA%95)。

:::

### generator-settings
作用：

用于调整超平坦和自定义世界的生成。详见[超平坦世界](https://zh.minecraft.wiki/w/%E8%B6%85%E5%B9%B3%E5%9D%A6%E4%B8%96%E7%95%8C)和[自定义](https://zh.minecraft.wiki/w/%E8%87%AA%E5%AE%9A%E4%B9%89)了解正确的设定及例子。

默认值：`{}`

允许值：任意字符串

### hardcore
作用：

是否开启极限模式。如果设为`true`，服务器难度的设置会被忽略并且锁定为**困难**难度，玩家在死后会自动切换至旁观模式。

默认值：`false`

允许值：`false` `true`

### hide-online-players
作用：

是否在多人游戏列表中隐藏在线玩家列表。

默认值：`false`

允许值：`false` `true`

### level-name
作用：

此项配置用于指定存档及其对应文件夹的名称。若服务器启动时未找到与该配置项同名的文件夹，则会自动创建一个新的存档。

默认值：`world`

允许值：任意字符串（部分符号需要在前面加上反斜杠转译）

:::info[提示]

在 Java 版 26.1 之前，插件端的存档被拆分为三个独立的文件夹：`world`（主世界）、`world_nether`（下界）和 `world_the_end`（末地）。更改此项配置的值时，上述三个文件夹名称中的 `world` 字段将同步被替换。

:::

### level-seed
作用：

此配置用于设置生成世界时使用的种子。但该配置仅在**首次生成世界时生效**；若服务器已有存档，修改此值不会产生任何影响。如需应用新种子，请先删除现有存档，让服务器重新生成世界。

默认值：空

允许值：任意字符串（部分符号需要在前面加上反斜杠转译）

### level-type
作用：

使用世界预设ID，确定地图所生成的类型。

默认值：`minecraft:normal`

允许值：

| 值 | 描述 |
| --- | --- |
| `minecraft:normal` | 默认，正常的世界 |
| `minecraft:flat` | 超平坦，可通过`generator-settings`自定义 |
| `minecraft:large_biomes` | [巨型生物群系](https://zh.minecraft.wiki/w/%E5%B7%A8%E5%9E%8B%E7%94%9F%E7%89%A9%E7%BE%A4%E7%B3%BB) |
| `minecraft:amplified` | [放大化世界](https://zh.minecraft.wiki/w/%E6%94%BE%E5%A4%A7%E5%8C%96) |
| `minecraft:single_biome_surface` | 单一生物群系，可通过`generator-settings`自定义 |
| `minecraft:buffet` | 自选，仅 1.13~1.15.2 之间的版本可用 |

### log-ips
作用：

是否在有新玩家加入游戏时，在服务器日志中记录其 IP 地址。

默认值：`true`

允许值：`false` `true`

:::info[提示]

此项配置自 1.20.2 版本加入。在此之前的版本中，服务器会始终记录玩家的 IP 地址。

:::

### max-build-height
作用：

限制玩家的最大建筑高度，**只能在原版范围内(0～256)限制！**

默认值：`256`

允许值：`0`~`256` 之间的整数

:::warning[提示]

此项配置已在 1.17 移除！

如果你想提升建筑高度限制，请去添加一个数据包或者mod！

:::

### max-players
作用：

服务器同时能容纳的最大玩家数量。

默认值：`20`

允许值：`0`~`2147483647` 之间的整数

:::info[提示]

服务器的 OP 具有在人满的情况下强行进入服务器的能力。

:::

### max-tick-time
作用：

设置每个 tick 花费的最大毫秒数。超过该毫秒数时，服务器 watchdog 插件将停止服务器程序并附带崩溃信息。

默认值：`60000`（60 秒）

允许值：`-1`~`9223372036854775807`（2的63次方减1）之间的整数

:::info[提示]

将此项设置为 `-1` 将禁用 watchdog 插件。

在模组服务器中，watchdog 可能会因模组导致的卡顿或延迟而误判并强制关闭服务器。因此，建议将值设为 `-1` 以完全禁用此功能。

:::

### max-world-size
作用：

设置可让世界边界获得的最大半径值，单位为方块。通过成功执行的命令能把世界边界设置得更大，但不会超过这里设置的最大方块限制。如果设置的max-world-size超过默认值的大小，那将不会起任何效果。

默认值：`29999984`

允许值：`1`~`29999984`之间的正整数

### motd
作用：

此项配置用于设置服务器在多人游戏列表中显示的欢迎信息（MOTD）。支持使用样式代码（`§`）来更改文本的颜色或格式，例如配置为 `§6密室杀手 - party.simpfun.net` 时，显示效果如下图所示：

![motd 显示效果示例](/img/pages/mcje/mcje-server_properties-1.png)

默认值：`A Minecraft Server`

允许值：任意字符串（部分符号需要在前面加上反斜杠转译）

:::info[提示]

+ 在不安装插件或 mod 的情况下，motd 只能配置 1 行内容。
+ 在 1.20 前，输入中文字符需要转译为 Unicode 编码，你可以使用[这个在线工具](https://www.metools.info/code/c39.html)来进行转换。

:::

### network-compression-threshold
作用：

配置数据包压缩阈值。默认会允许 n-1 字节的数据包正常发送, 如果数据包为 n 字节或更大时会进行压缩。所以，更低的数值会使得更多的数据包被压缩，但是如果被压缩的数据包字节太小将反而使压缩后字节更大。

默认值：`256`

允许值：整数

+ 设置为 `-1` 时将完全禁用数据包压缩。
+ 设置为 `0` 时将压缩全部数据包。

:::info[提示]

以太网规范要求把小于 64 字节的数据包填充为 64 字节。因此，设置一个低于 64 的值可能没有什么好处。也不推荐让设置的值超过 [MTU](https://info.support.huawei.com/info-finder/encyclopedia/zh/MTU.html)（通常为 1500 字节）。

:::

### online-mode
作用：

此项配置用于控制是否开启正版验证。

+ 启用：玩家加入服务器时需要进行正版验证
+ 禁用：不进行任何验证，任何人都可直接加入

如果使用了修改验证服务器的第三方登录系统，启用后服务器将连接第三方 API 进行身份验证；禁用则跳过验证过程。

默认值：`true`

允许值：`false` `true`

### op-permission-level
作用：

设定使用`/op`命令添加管理员时的默认[权限等级](https://zh.minecraft.wiki/w/%E6%9D%83%E9%99%90%E7%AD%89%E7%BA%A7)。

如果你想要单独设置某个玩家的权限等级，可以前往`ops.json`进行设置。

默认值：`4`

允许值：`1`~`4` 之间的整数

### pause-when-empty-seconds
作用：

服务器在没有玩家在线指定秒数后自动停止计算。

当服务器停止计算时，每个游戏刻服务器都不会再做任何事。这导致游戏中几乎所有事物都暂停了：

+ 世界内不会有任何更新，包括方块更新、实体移动和随机刻。
+ 所有的自动化农场和红石装置都会暂停，即使它们在强加载区块或是出生点区块中。
+ 游戏内时间会被暂停，防止世界内的区域难度增加。

默认值：`60`

允许值：整数

+ 设置为负数则不会自动停止计算。

:::info[提示]

此项配置在`1.21.2`加入。

这条配置相当于某些暂停服务器计算的 mod/插件，例如 [Tick Stasis ](https://www.mcmod.cn/class/10630.html)，[Hibernate](https://www.spigotmc.org/resources/hibernate.4441/) 等。

:::

### player-idle-timeout
作用：

如果设置的值不为 0，服务器将在玩家的空闲时间达到设置的时间（单位为分钟）时将玩家踢出服务器。

默认值：0

允许值：正整数

:::info[提示]

如果服务器公开且流量大建议开启此项配置。

当服务器接受到下列数据包之一时将会重置空闲时间：

+ [点击窗口](https://minecraft.wiki/w/Minecraft_Wiki:Projects/wiki.vg_merge/Protocol#Click_Container)

### pvp
作用：

启用后，玩家可以互相攻击。

默认值：`true`

允许值：`false` `true`

:::warning[提示]

此项配置在 1.21.9 的快照 25w35a 后失效，使用游戏规则`[pvp](https://zh.minecraft.wiki/w/%E6%B8%B8%E6%88%8F%E8%A7%84%E5%88%99/pvp)`替代。

:::

### rate-limit
作用：

设置玩家被踢出服务器前，可以发送的数据包数量。

默认值：`0`

允许值：大于等于`0`的整数

+ 设置为`0`表示关闭此功能。

### region-file-compression
作用：

设置区域文件压缩算法。

默认值：`deflate`

允许值：

| 值 | 描述 |
| --- | --- |
| `deflate` | 区域文件使用 Deflate 算法压缩（存档体积最小，效率最低）。 |
| `lz4` | 区域文件使用 LZ4 算法压缩（兼顾存档体积和效率）。 |
| `none` | 区域文件不进行压缩（存档体积最大，除非硬盘速度很低，否则效率最高）。 |

:::info[提示]

此项配置在`1.20.5`加入。

:::

### require-resource-pack
作用：

该配置项用于设定服务端是否强制客户端接受资源包。启用时，玩家加入服务器将收到资源包提示，若拒绝加载则会被断开连接。禁用时，资源包的加载与否由客户端本地设置自行决定。

默认值：`false`

允许值：`false` `true`

### resource-pack
作用：

可选选项，可输入指向一个资源包的URI。玩家可选择是否使用该资源包。

默认值：空

允许值：空值，或者为一个可访问的资源包压缩包**直链**下载地址。

+ 示例：`https://example.com/resourcepack.zip`
+ 留空则不会启用此功能。

:::info[提示]

URI 中的`:`与`=`字符须使用反斜线（`\`）进行转义，示例：`http\://somedomain.com/somepack.zip?someparam\=somevalue`。

资源包文件大小受服务端版本限制，具体阈值如下：

+ 1.15-pre5 之前：50 MiB
+ 1.15-pre5 至 1.18-pre8：100 MiB
+ 1.18-rc1 起：250 MiB

:::

### server-ip
作用：

指定服务端监听的 IP。

默认值：空

可选值：有效的 IPv4 地址或 IPv6 地址

:::warning[警告]

在简幻欢平台中，此项配置应填写为 `0.0.0.0`。所有预设的 Minecraft Java 版镜像以及大部分第三方镜像，在启动实例时都会自动将此值覆写为 `0.0.0.0`。

:::

### server-port
作用：

指定服务端监听的端口。

默认值：`25565`

允许值：`1`~`65535`（所有有效的端口号）

:::warning[警告]

此项配置应填写为您的实例分配到的端口号。所有预设的 Minecraft Java 版镜像及大部分第三方镜像，在启动实例时会自动将该值覆盖为实际分配的端口，您无需手动设置。

:::

### simulation-distance
作用：

此项配置用于设置服务端可更新实体的最大范围（即模拟距离），数值表示玩家**各个方向上加载的区块数量**（以玩家为中心，该值为**半径**，而非直径）。超出此范围的实体将不会被更新，同时对玩家不可见。

默认值：`10`

允许值：`3`~`32`

:::warning[提示]

模拟距离越大，服务端需要更新的实体就越多，对性能的消耗也越大。如果您的服务器经常出现卡顿，可以尝试适当调低此值来缓解压力。

:::

:::info[提示]

此项配置在 1.18 的快照 21w38a 加入，在此之前的版本中，模拟距离与渲染距离相等。

:::

### spawn-animals
作用：

决定服务器是否生成动物，关闭则生成后立刻消失。

默认值：`true`

允许值：`false` `true`

:::warning[提示]

此项配置在 1.21.2 移除。

:::

### spawn-monsters
作用：

决定服务器是否生成怪物，关闭则不会生成。如果`difficulty=peaceful`（即游戏难度为和平），此项不会有任何影响。

默认值：`true`

允许值：`false` `true`

:::warning[提示]

此项配置在 1.21.9 的快照 25w35a 后失效，使用游戏规则 `[spawn_monsters](https://zh.minecraft.wiki/w/%E6%B8%B8%E6%88%8F%E8%A7%84%E5%88%99/spawnMonsters)` 替代。

:::

### spawn-npcs
作用：

决定服务器是否生成村民，关闭则不会生成。

默认值：`true`

允许值：`false` `true`

:::warning[提示]

此项配置在 1.21.2 移除。

:::

### spawn-protection
作用：

通过将该值进行 2x+1 的运算来决定出生点的保护半径。例如，如果设置为`3`则会保护世界出生点周围 7x7 方块内的区域。

默认值：`16`

允许值：整数

+ 设置为`0`或负数将会禁用出生点保护。

### use-native-transport
作用：

是否使用针对 Linux 平台的数据包收发优化。这可以提升 Linux 上服务器的性能。

默认值：`true`

允许值：`false` `true`

### view-distance
作用：

此项配置用于设置服务端发送给客户端的世界数据量，即玩家各个方向上加载的区块数量（以玩家为中心，该值为半径，而非直径）。它决定了服务端的[可视距离](https://zh.minecraft.wiki/w/%E6%B8%B2%E6%9F%93%E8%B7%9D%E7%A6%BB)。

默认值：`10`

允许值：`2`~`32`

:::warning[提示]

渲染距离越大，服务端需要发送给客户端的数据量就越多，对网络带宽和性能的消耗也越大。如果您的服务器经常出现卡顿，可以尝试适当调低此值来缓解压力。

:::

### white-list
作用：

是否启用服务器的白名单，当启用时，只有白名单上的用户才能连接服务器。白名单主要用于私人服务器，例如提供给相识的朋友、通过互联网谨慎选择的陌生人等。

默认值：`false`（26.2 及之前）/ `true`（26.3 及之后）

允许值：`false` `true`

:::warning[警告]

您必须启用正版才能正确的使用这个功能，否则会遇到未知错误！

:::

:::info[提示]

OP 会自动被视为在白名单上，所以无需再将 OP 加入白名单。

:::
