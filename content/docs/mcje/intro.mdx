这里是 **Minecraft Java 版（MCJE）** 服务端相关文档。

可适用绝大部分情况，即使你不使用简幻欢，也可查阅学习。

部分仅适用简幻欢场景的情况将会标注。

## 快速开始

1. 在官网创建实例，选择 Java 版镜像。
2. 选择服务端核心（Vanilla / Paper / Fabric / Forge 等）。
3. 接受 EULA，配置 `server.properties`，然后启动。

<Callout type="warn" title="注意">

模组与插件分属不同生态，不能混用。请在开服前确认你需要的到底是模组还是插件。

</Callout>
