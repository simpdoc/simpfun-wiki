## 1.17.1 及以上版本的服务端

<Callout type="warn" title="提示">

+ 从 1.17.1 开始，Forge 的启动命令是启动一个 txt 文件，你在根目录下是找不到 Forge/原版核心的！
+ 从 1.20.4 开始，Forge 在构建服务端时会在根目录生成一个类似 `forge-1.20.6-50.0.29-shim.jar` 名字的文件，目前暂不清楚此文件有什么作用。

</Callout>

### 第一步：构建服务端

打开 [Forge 官网](https://files.minecraftforge.net/net/minecraftforge/forge/)，选择你需要的版本的 Forge 安装器进行下载，此处以 1.17.1 为例。按下图方式下载安装器可以跳过下载前的广告。

![Forge 官网中跳过广告直接下载安装器的方式](/img/pages/mcje/mcje-forge-3.png)

<Callout type="info" title="其他下载地址">

无极镜像（CN）：[https://www.fastmirror.net/#/download/Forge](https://www.fastmirror.net/#/download/Forge)

</Callout>

下载完成后，将其上传至实例文件的根目录。

打开根目录下的 `start.sh`，在文件内添加一行下面的命令后保存（不要删除 `start.sh` 自带的东西，`echo` 那一行除外）：

```shell title="start.sh"
${openjdk17} -server -Dfile.encoding=UTF-8 -Duser.language=zh -Duser.country=CN -jar [Forge安装器文件名].jar --installServer
```

PS：使用时去掉方括号。

如下图第 17 行所示：

![start.sh 中新增的 Forge 安装器命令](/img/pages/mcje/mcje-forge-4.png)

回到「终端」界面，启动实例。等待服务端构建完成后，会出现以下输出并停止运行。

```plain
The server installed successfully
You can delete this installer file now if you wish
```

### 第二步：调整启动命令

转到「文件」界面，打开根目录下自动生成的 `run.sh`，**复制类似下方的参数**（最前面的 java 不用复制）：

```shell title="run.sh"
@libraries/net/minecraftforge/forge/1.17.1-37.1.1/unix_args.txt "$@"
```

打开 `start.sh`，删除第一步中添加的命令（防止重新构建毁坏服务端），并添加一行**类似**下方的命令后保存：

```shell title="start.sh"
${openjdk17} -server -Xms1024m -Xmx${maxmem}M @libraries/net/minecraftforge/forge/1.17.1-37.1.1/unix_args.txt "$@" nogui
```

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk17}`：调用变量 `openjdk17`。请按下方的版本对照选择对应的变量，例如 1.21 应写成 `${openjdk21}`；26.1+ 需要 Java 25，而 AIO v1 镜像未内置，需自行导入后再调用。
  + 1.17.1——1.20.4 需要 Java 17 或更高版本
  + 1.20.5——1.21.11 需要 Java 21 或更高版本
  + 26.1+ 需要 Java 25 或更高版本
+ `-server`：指示 JVM 在服务器环境中运行。这是一个优化标记，告诉 JVM 使用更适合长时间运行和高性能的配置。
+ `-Xms1024M`：服务器运行最小内存为 1024 MiB。`1024M` 可以修改：如果觉得最小运存太大，可以改为 `512M` 或其他值，只要数字部分是 4 的倍数；也可以写成 `1G`，效果相同。
+ `-Xmx${maxmem}M`：服务器运行最大内存为 `maxmem` M，`maxmem` 是上文定义的变量，值为服务器最大物理内存减 1000（单位 M）。**注意：`Xmx` 与 `Xms` 均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**
+ `@libraries/net/minecraftforge/forge/1.17.1-37.1.1/unix_args.txt "$@"`：**此处请填写你在 `run.sh` 内复制的参数！** 它引用了用户定义的 JVM 参数文件与 Forge 所需的 UNIX 启动参数文件，再把这些参数传给 Forge 的执行命令。**不同 Forge 版本此参数里的版本号不同。**
+ `nogui`：不启用 MC 服务端自带的 GUI 窗口，在面板服/命令行环境运行服务端时不能删。

</Callout>

调整完的启动命令应如下图所示：

![start.sh 中修改后的 Forge 启动命令](/img/pages/mcje/mcje-forge-5.png)

此时你可以将 Forge 安装器删除了。

### 第三步：同意 EULA

启动服务器，稍微等待一会后会出现类似如下的提示并关闭服务器：

```plain
[16:28:45] [main/INFO] [minecraft/Main]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

转到「文件」页面，打开根目录下的 `eula.txt`。

```properties title="eula.txt"
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Sat Nov 18 16:28:45 CST 2023
eula=false
```

将其中的 `false` 改为 `true`。

<Callout type="error" title="警告">

将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

</Callout>

回到「终端」界面，点击右上角的「启动」，等待服务器生成文件。看到类似以下的提示即可关闭服务端：

```plain
[16:30:15 INFO]: Done (27.102s)! For help, type "help"
```

### 第四步：配置服务端

再次进入「文件」页面，打开根目录下的 `server.properties`。

简幻欢在上一步启动服务端生成文件时，已自动修改 `server-ip` 为 `0.0.0.0`、`server-port` 为你实例分配到的端口号，因此这两个不用管。

如果你或你的朋友没有正版账户，请把 `online-mode` 的值由 `true` 改为 `false`。请注意，这样做会显著增加你的服务器遭受恶意攻击的风险！

更多关于服务器设置的配置请查看 [server.properties 详解](/docs/mcje/server_properties)。Mod 文件放入 `mods` 文件夹。

现在你已经配置好服务端了，去愉快地玩游戏吧！

## 1.7.10——1.16.5 版本的服务端

1.16.5 及以下版本的 Forge 服务端是使用一个 jar 文件启动的。

### 第一步：安装服务端

打开 [Forge 官网](https://files.minecraftforge.net/net/minecraftforge/forge/)，选择你需要的版本的 Forge 安装器进行下载，此处以 1.12.2 为例。按下图方式下载 Forge 安装器，可以跳过广告。

![Forge 官网中按 Minecraft 版本选择安装器的位置](/img/pages/mcje/mcje-forge-6.png)

<Callout type="info" title="其他下载地址">

无极镜像（CN）：[https://www.fastmirror.net/#/download/Forge](https://www.fastmirror.net/#/download/Forge)

</Callout>

下载完成后，将其上传至实例文件的根目录。

打开根目录下的 `start.sh`，在文件内添加一行下面的命令后保存（不要删除 `start.sh` 自带的东西，`echo` 那一行除外）：

```shell title="start.sh"
${openjdk8} -server -Dfile.encoding=UTF-8 -Duser.language=zh -Duser.country=CN -jar [Forge安装器文件名].jar --installServer
```

PS：使用时去掉方括号。

如下图所示：

![start.sh 中新增的 Forge 安装器命令](/img/pages/mcje/mcje-forge-7.png)

回到「终端」界面，启动实例。等待服务端构建完成后，会出现以下输出并停止运行。

```plain
The server installed successfully
You can delete this installer file now if you wish
```

### 第二步：调整启动命令

打开 `start.sh`，删除第一步中添加的命令（防止重新构建毁坏服务端），并添加一行类似下方的命令后保存：

```shell title="start.sh"
${openjdk8} -server -Xms1024M -Xmx${maxmem}M -Dfile.encoding=UTF-8 -Duser.language=zh -Duser.country=CN -jar [服务端名字].jar -nogui
```

<Callout type="info" title="提示">

`[服务端名字]` 指的是构建出的 Forge 核心，例如上图中目录里的 `forge-1.12.2-14.23.5.2860.jar`。

</Callout>

![构建完成后根目录中生成的 Forge 核心文件](/img/pages/mcje/mcje-forge-8.png)

<Callout type="warn" title="提示">

不要试图启动 `minecraft_server.x.x.x.jar`，不然会喜提「不加载 mod」。

</Callout>

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk8}`：调用变量 `openjdk8`，这个变量在上面的默认内容里已经定义过了。部分版本的 mod 可能需要 Java 11（例如 1.16.5）。
+ `-server`：指示 JVM 在服务器环境中运行。这是一个优化标记，告诉 JVM 使用更适合长时间运行和高性能的配置。
+ `-Xms1024M`：服务器运行最小内存为 1024 MiB。`1024M` 可以修改：如果觉得最小运存太大，可以改为 `512M` 或其他值，只要数字部分是 4 的倍数；也可以写成 `1G`，效果相同。
+ `-Xmx${maxmem}M`：服务器运行最大内存为 `maxmem` M，`maxmem` 是上文定义的变量，值为服务器最大物理内存减 1000（单位 M）。**注意：`Xmx` 与 `Xms` 均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**
+ `nogui`：不启用 MC 服务端自带的 GUI 窗口，在面板服/命令行环境运行服务端时不能删。

</Callout>

调整完的启动命令应类似下图所示：

![start.sh 中修改后的 Forge 启动命令](/img/pages/mcje/mcje-forge-9.png)

此时你可以将 Forge 安装器删除了。

启动服务器，稍微等待一会后会出现类似如下的提示并关闭服务器：


<Callout type="error" title="警告">
