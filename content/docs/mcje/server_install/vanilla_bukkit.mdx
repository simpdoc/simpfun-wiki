本篇文档介绍如何在简幻欢实例中手动安装预设未提供的原版（Vanilla）与 Bukkit 系（插件）服务端。

## Vanilla 端 / 大部分 Bukkit 系服务端

Vanilla 服务端与大部分 Bukkit 系服务端（Spigot 除外）的安装流程基本一致，此处以 **Paper 1.19.2** 为例进行演示。服务器使用简幻欢的 Java 自定义镜像。

### 第一步：下载服务端核心

在 [Paper 官网](https://fill-ui.papermc.io/projects/paper) 下载与目标版本对应的服务端核心。

![PaperMC Fill 页面上按 Minecraft 版本分类的核心列表](/img/pages/mcje/mcje-vanilla_bukkit-1.webp)

<Callout type="info" title="其它服务端下载地址">

Vanilla（原版）服务端：

+ 官方渠道（仅提供最新版本，不推荐用于安装历史版本）：[https://www.minecraft.net/zh-hans/download/server](https://www.minecraft.net/zh-hans/download/server)
+ 无极镜像（CN）：[https://www.fastmirror.net/#/download/Vanilla](https://www.fastmirror.net/#/download/Vanilla?coreVersion=release)

其它 Bukkit 系服务端核心：

+ Paper：无极镜像（CN）[https://www.fastmirror.net/#/download/Paper](https://www.fastmirror.net/#/download/Paper)
+ Purpur：官方 [https://purpurmc.org/downloads](https://purpurmc.org/downloads) / 无极镜像（CN）[https://www.fastmirror.net/#/download/Purpur](https://www.fastmirror.net/#/download/Purpur)
+ Leaves：官方 [https://leavesmc.org/downloads/all](https://leavesmc.org/downloads/all)
+ Folia：官方 [https://papermc.io/downloads/folia](https://papermc.io/downloads/folia) / 无极镜像（CN）[https://www.fastmirror.net/#/download/Folia](https://www.fastmirror.net/#/download/Folia)

</Callout>

### 第二步：上传服务端核心

将下载好的服务端核心上传至实例根目录。

上传完成后，请记下其完整文件名（含扩展名）。

编辑实例根目录下的 `start.sh`，在文件末尾追加一行与下方类似的启动命令后保存。除文件中最后一行的 `echo` 外，请勿删除已有内容：

```shell title="start.sh"
${openjdk17} -server -Xms1024M -Xmx${maxmem}M -jar paper-1.19.2-307.jar nogui
```

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk17}`：用来运行服务端的 Java 程序。不同 Minecraft 版本需要不同版本的 Java，请按下表把这一项换成对应的变量：
  + 1.7.10——1.16.5：`${openjdk8}`（1.16.5 也可以用 `${openjdk11}`）
  + 1.17——1.20.4：`${openjdk17}`
  + 1.20.5——1.21.11：`${openjdk21}`
  + 26.1 及之后：`${openjdk25}`
+ `-server`：让 Java 知道这是一个长期开着的服务器程序，按服务器的需要来运行。
+ `-Xms1024M`：**最小分配内存**，这里是 1024 MiB（也就是 1 GiB）。可以先少给一些，不够再调大，例如改成 `512M` 或 `1G`。
+ `-Xmx${maxmem}M`：**最大分配内存**，服务器最多能用这么多内存；`maxmem` 会自动取「实例可用内存减去 1000」。**注意：最大内存不要超过实例的内存上限，也不能比最小内存还小，否则服务器会启动失败！**
+ `-jar`：表示接下来要运行一个 jar 文件，这一项不用改。
+ `paper-1.19.2-307.jar`：要运行的服务端文件，改成你自己上传的文件名（含 `.jar` 后缀）。
+ `nogui`：不打开服务端的图形窗口。面板服没有桌面窗口，所以这一项必须保留。

</Callout>

### 第三步：初始化服务器

返回「终端」页面，点击右上角的「启动」，等待服务端下载并解压所需文件。Vanilla 服务端本身不含额外下载步骤。

首次启动会因未同意 EULA 而终止，终端输出类似以下内容：

```plain
[15:44:52 WARN]: Failed to load eula.txt
[15:44:52 INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

### 第四步：同意 EULA

进入「文件」页面，打开实例根目录下的 `eula.txt`：

```properties title="eula.txt"
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Fri Nov 17 15:44:52 CST 2023
eula=false
```

将其中的 `eula=false` 改为 `eula=true` 后保存。

<Callout type="error" title="警告">

将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

</Callout>

返回「终端」页面，点击右上角的「启动」，等待服务端生成配置文件。出现类似以下提示后即可关闭服务端：

```plain
[15:58:15 INFO]: Done (34.635s)! For help, type "help"
```

### 第五步：配置服务器

进入「文件」页面，打开实例根目录下的 `server.properties`。

实例在首次启动生成该文件时，已自动将 `server-ip` 设为 `0.0.0.0`，并将 `server-port` 设为本实例分配的端口号，因此这两项无需修改。

若你或你的朋友没有正版账户，可将 `online-mode` 由 `true` 改为 `false`。请注意，这会关闭正版验证，并显著增加服务器遭受恶意攻击的风险。

更多配置项说明请参见 [server.properties 详解](/docs/mcje/server_properties)。

<Callout type="info" title="提示">

Vanilla 服务端不支持加载模组（mod）或插件（plugin）。

Bukkit 系服务端如需安装插件，将插件文件放入实例根目录下的 `plugins` 文件夹即可。

</Callout>

至此，服务端已完成基础配置，可以启动并进入游戏。

  ### 第一步：构建服务端核心

  前往 [Spigot 构建站](https://hub.spigotmc.org/jenkins/job/BuildTools/) 下载 `BuildTools.jar`。

  ![Spigot 构建站中 BuildTools.jar 的下载入口](/img/pages/mcje/mcje-vanilla_bukkit-3.webp)

  将 `BuildTools.jar` 上传至实例根目录，并在根目录下的 `start.sh` 中添加一行以下命令后保存（除文件最后一行的 `echo` 外，请勿删除已有内容）：

  ```shell title="start.sh"
  ${openjdk17} -Xmx1500m -jar BuildTools.jar --rev 版本号
  ```

  `--rev` 后的版本号替换为需要构建的版本，例如 `1.19.3`；设为 `latest` 时构建最新版本。

  ![start.sh 中新增的 BuildTools 构建命令](/img/pages/mcje/mcje-vanilla_bukkit-4.webp)

  保存完成后启动实例，等待构建完成。

  ### 第二步：初始化服务端

  打开实例根目录下的 `start.sh`，先删除第一步添加的这行命令：

  ```shell title="start.sh"

  ```

  然后再添加一行与下方类似的启动命令后保存（除文件中最后一行的 `echo` 外，请勿删除已有内容）：


  </Callout>

  调整后的启动命令应类似下图所示：

  ![start.sh 中修改后的 Spigot 启动命令](/img/pages/mcje/mcje-vanilla_bukkit-5.webp)

  此时可将 `BuildTools.jar` 删除。

  返回「终端」页面，点击右上角的「启动」。
