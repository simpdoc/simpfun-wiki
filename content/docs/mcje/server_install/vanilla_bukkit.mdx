本篇文档会教你如何安装简幻欢没有的原版/插件服务端。

## Vanilla 端 / 大部分 Bukkit 系服务端

Vanilla 端与大部分 Bukkit 系服务端（Spigot 除外）的安装过程较为简单，此处以 **Paper 1.19.2** 进行演示。服务器使用简幻欢 Java 自定义镜像。

### 第一步：下载服务端核心

在 [Paper 官网](https://fill-ui.papermc.io/projects/paper)下载对应版本的服务端核心。

![PaperMC Fill 页面上按 Minecraft 版本分类的核心列表](/img/pages/mcje/mcje-vanilla_bukkit-1.webp)

<Callout type="info" title="其它服务端下载地址">

Vanilla（原版）服务端：

+ 官方（不建议，只能下载到最新版本）：[https://www.minecraft.net/zh-hans/download/server](https://www.minecraft.net/zh-hans/download/server)
+ 无极镜像（CN）：[https://www.fastmirror.net/#/download/Vanilla](https://www.fastmirror.net/#/download/Vanilla?coreVersion=release)

其他 Bukkit 系服务端核心：

+ Paper：无极镜像（CN）[https://www.fastmirror.net/#/download/Paper](https://www.fastmirror.net/#/download/Paper)
+ Purpur：官方 [https://purpurmc.org/downloads](https://purpurmc.org/downloads) / 无极镜像（CN）[https://www.fastmirror.net/#/download/Purpur](https://www.fastmirror.net/#/download/Purpur)
+ Leaves：官方 [https://leavesmc.org/downloads/all](https://leavesmc.org/downloads/all)
+ Folia：官方 [https://papermc.io/downloads/folia](https://papermc.io/downloads/folia) / 无极镜像（CN）[https://www.fastmirror.net/#/download/Folia](https://www.fastmirror.net/#/download/Folia)

</Callout>

### 第二步：上传服务端核心

上传你下载好的服务端核心到简幻欢的根目录。

确定服务端核心已上传后，**记住文件名（包括后缀名！）**。

打开根目录下的 `start.sh`，添加一行**类似**下面的命令后保存（不要删除文件里原本的东西，除了最下面那行 `echo`）：

```shell title="start.sh"
${openjdk17} -server -Xms1024M -Xmx${maxmem}M -jar paper-1.19.2-307.jar nogui
```

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk17}`：调用变量 `openjdk17`，这个变量在上面的默认内容里已经定义过了。1.16.5 及以下版本的服务端请将 `openjdk17` 改为 `openjdk8` 或 `openjdk11`。
+ `-server`：指示 JVM 在服务器环境中运行。这是一个优化标记，告诉 JVM 使用更适合长时间运行和高性能的配置。
+ `-Xms1024M`：服务器运行最小内存为 1024 MiB。`1024M` 可以修改：如果觉得最小运存太大，可以改为 `512M` 或其他值，只要数字部分是 4 的倍数；也可以写成 `1G`，效果相同。
+ `-Xmx${maxmem}M`：服务器运行最大内存为 `maxmem` M。`maxmem` 是上文定义的变量，值为服务器最大物理内存减 1000（单位 M）。如果不想要这个变量名，可以把 `${maxmem}` 整个改成数字。**注意：`Xmx` 与 `Xms` 均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**
+ `-jar`：告诉 Java 要启动 jar 文件，此项不要调整。
+ `paper-1.19.2-307.jar`：服务端核心名称，**改成自己上传的，包括刚才让你记的后缀名！**
+ `nogui`：不启用 MC 服务端自带的 GUI 窗口，在面板服/命令行环境运行服务端时不能删。

</Callout>

### 第三步：初始化服务器

回到「终端」界面，点击右上角的「启动」，并等待文件下载完成。Vanilla 端不会下载文件。

下载完成后，终端会输出类似下面的提示并停止运行：

```plain
[15:44:52 WARN]: Failed to load eula.txt
[15:44:52 INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

### 第四步：同意 EULA

进入「文件」页面，打开根目录下的 `eula.txt`。

```properties title="eula.txt"
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Fri Nov 17 15:44:52 CST 2023
eula=false
```

将其中的 `false` 改为 `true`，然后保存。

<Callout type="error" title="警告">

将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

</Callout>

回到「终端」界面，点击右上角的「启动」，等待服务器生成文件。看到类似以下的提示即可关闭服务端：

```plain
[15:58:15 INFO]: Done (34.635s)! For help, type "help"
```

### 第五步：配置服务器

再次进入「文件」页面，打开根目录下的 `server.properties`。

简幻欢在上一步启动服务端生成文件时，已自动修改 `server-ip` 为 `0.0.0.0`、`server-port` 为你实例分配到的端口号，因此这两个不用管。

如果你或你的朋友没有正版账户，请把 `online-mode` 的值由 `true` 改为 `false`。请注意，这样做会显著增加你的服务器遭受恶意攻击的风险！

更多关于服务器设置的配置请查看 [server.properties 详解](/docs/mcje/server_properties)。

<Callout type="info" title="提示">

Vanilla 服务端无法装载 mod/插件。

Bukkit 系服务端需要装载插件的话，将插件放到 `plugins` 文件夹即可。

</Callout>

现在你已经配置好服务端了，去进行愉快的游戏吧！

  <Callout type="error" title="注意">

  由于国内下载速度极其缓慢，因此不建议使用此方法在简幻欢上手动构建服务端。如果非常需要此服务端，可以前往镜像站下载，或在有良好网络环境的本地电脑上构建。

  前往下方镜像站下载已构建完成的 Spigot 服务端：

  + 无极镜像（CN）：[https://www.fastmirror.net/#/download/Spigot](https://www.fastmirror.net/#/download/Spigot)
  + 国外镜像站：[https://serverjar.org/download-version/spigot](https://serverjar.org/download-version/spigot)

  </Callout>

  ### 第一步：构建服务端核心

  前往 [Spigot 构建站](https://hub.spigotmc.org/jenkins/job/BuildTools/)下载 `BuildTools.jar`。

  ![Spigot 构建站中 BuildTools.jar 的下载入口](/img/pages/mcje/mcje-vanilla_bukkit-3.webp)

  将 `BuildTools.jar` 上传至实例文件的根目录，并在根目录下的 `start.sh` 内添加一行下面的命令后保存（不要删除 `start.sh` 自带的东西，`echo` 那一行除外）：

  ```shell title="start.sh"
  ${openjdk17} -Xmx1500m -jar BuildTools.jar --rev 版本号
  ```

  `--rev` 后的版本号换成你想构建的版本，例如 `1.19.3`；设置为 `latest` 时构建最新版本。

  ![start.sh 中新增的 BuildTools 构建命令](/img/pages/mcje/mcje-vanilla_bukkit-4.webp)

  保存完成后启动实例，等待服务端构建完毕。

  ### 第二步：初始化服务端

  打开根目录下的 `start.sh`，先把第一步添加的这行命令删除：

  ```shell title="start.sh"
  ${openjdk17} -Xmx1500m -jar BuildTools.jar --rev 版本号
  ```

  然后再添加一行类似下面的命令后保存（不要删除文件里原本的东西，除了最下面那行 `echo`）：

  ```shell title="start.sh"
  ${openjdk17} -server -Xms1024M -Xmx${maxmem}M -jar Spigot-1.20.2-3941.jar nogui
  ```

  <Callout type="info" title="关于各项参数的说明">

  各项参数的含义与上文 Paper 的说明相同，只需要把 `Spigot-1.20.2-3941.jar` 换成你自己构建出的服务端核心名称（包括后缀名）。

  </Callout>

  调整完的启动命令应类似下图所示：

  ![start.sh 中修改后的 Spigot 启动命令](/img/pages/mcje/mcje-vanilla_bukkit-5.webp)

  此时你可以将 `BuildTools.jar` 删除了。

  回到「终端」界面，点击右上角的「启动」。

  文件释放完成后，终端会输出类似下面的提示并停止运行：

  ```plain
  [15:44:52 WARN]: Failed to load eula.txt
  [15:44:52 INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
  ```

  ```properties title="eula.txt"
  #By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
  #Fri Nov 17 15:44:52 CST 2023
  eula=false
  ```

  将其中的 `false` 改为 `true`。

  <Callout type="error" title="警告">

  将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

  </Callout>

  回到「终端」界面，点击右上角的「启动」，等待服务器生成文件。看到类似以下的提示即可关闭服务端：
