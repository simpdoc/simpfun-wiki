## 图文教程

<Callout type="warn" title="提示">

从 1.17.1 开始，Forge 的启动命令是启动一个 txt 文件，分叉后的 NeoForge 依旧保留了这一特性，你在根目录下是找不到 NeoForge/原版核心的！

</Callout>

### 第一步：安装服务端

**1.20.1：**

由于官网已撤下并且不再更新 1.20.1 的 NeoForge，因此请前往下方地址下载最后一个版本的 1.20.1 的 NeoForge：

[NeoForged Maven](https://maven.neoforged.net/#/releases/net/neoforged/forge/1.20.1-47.1.106)

进入后下载此文件：

![NeoForged Maven 中 1.20.1 安装器的下载入口](/img/pages/mcje/mcje-neoforge-2.png)

**1.20.2 及更高版本：**

打开 [NeoForge 官网](https://neoforged.net/)，按下图方式操作：

![NeoForge 官网中下载安装器的位置](/img/pages/mcje/mcje-neoforge-3.png)

下载完成后，将其上传至实例文件的根目录。

打开根目录下的 `start.sh`，在文件内添加一行下面的命令后保存（不要删除 `start.sh` 自带的东西，`echo` 那一行除外）：

```shell title="start.sh"
${openjdk21} -server -Dfile.encoding=UTF-8 -Duser.language=zh -Duser.country=CN -jar [NeoForge安装器文件名].jar --installServer
```

PS：使用时去掉方括号。

如下图第 14 行所示：

![start.sh 中新增的 NeoForge 安装器命令](/img/pages/mcje/mcje-neoforge-4.png)

回到「终端」界面，启动实例。等待服务端构建完成后，会出现以下输出并停止运行。

```plain
The server installed successfully
You can delete this installer file now if you wish
```

### 第二步：调整启动命令

转到「文件」界面，打开根目录下自动生成的 `run.sh`，复制类似下方的命令（最前面的 java 不用复制）：

```shell title="run.sh"
@libraries/net/neoforged/neoforge/20.4.217/unix_args.txt "$@"
```

打开 `start.sh`，删除第一步中添加的命令（防止重新构建毁坏服务端），并添加一行类似下方的命令后保存。由于项目名称的更改，NeoForge 的启动命令应类似如下格式：

```shell title="start.sh"
# 1.20.1
${openjdk17} -server -Xms1024M -Xmx${maxmem}M @libraries/net/neoforged/forge/1.20.1-47.1.106/unix_args.txt "$@" -nogui
# 1.20.2+
${openjdk21} -server -Xms1024M -Xmx${maxmem}M @libraries/net/neoforged/neoforge/20.4.217/unix_args.txt "$@" -nogui
```

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk17}`：调用变量 `openjdk17`。请按下方的版本对照选择对应的变量，例如 1.21 应写成 `${openjdk21}`；26.1+ 需要 Java 25，而 AIO v1 镜像未内置，需自行导入后再调用。
  + 1.20.1——1.20.4 需要 Java 17 或更高版本
  + 1.20.5——1.21.11 需要 Java 21 或更高版本
  + 26.1+ 需要 Java 25 或更高版本
+ `-server`：指示 JVM 在服务器环境中运行。这是一个优化标记，告诉 JVM 使用更适合长时间运行和高性能的配置。
+ `-Xms1024M`：服务器运行最小内存为 1024 MiB。`1024M` 可以修改：如果觉得最小运存太大，可以改为 `512M` 或其他值，只要数字部分是 4 的倍数；也可以写成 `1G`，效果相同。
+ `-Xmx${maxmem}M`：服务器运行最大内存为 `maxmem` M，`maxmem` 是上文定义的变量，值为服务器最大物理内存减 1000（单位 M）。**注意：`Xmx` 与 `Xms` 均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**
+ `@libraries/net/neoforged/neoforge/20.4.217/unix_args.txt "$@"`：**此处请填写你在 `run.sh` 内复制的参数！** 不同 NeoForge 版本此参数里的版本号不同。
+ `nogui`：不启用 MC 服务端自带的 GUI 窗口，在面板服/命令行环境运行服务端时不能删。

</Callout>

调整完的启动命令应类似下图所示：

![start.sh 中修改后的 NeoForge 启动命令](/img/pages/mcje/mcje-neoforge-5.png)

此时你可以将 NeoForge 安装器删除了。

### 第三步：同意 EULA

启动服务器，稍微等待一会后会出现类似如下的提示并关闭服务器：

```plain
[16:28:45] [main/INFO] [minecraft/Main]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

转到「文件」页面，打开根目录下的 `eula.txt`。

```properties title="eula.txt"
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
eula=false
```

将其中的 `false` 改为 `true`。

<Callout type="error" title="警告">

将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

此外，若你需安装整合包，应在修改 EULA 后**不启动服务器**，待内容全部正确导入后再启动。

</Callout>

回到「终端」界面，点击右上角的「启动」，等待服务器生成文件。看到类似以下的提示即可关闭服务端：

```plain
[16:30:15 INFO]: Done (27.102s)! For help, type "help"
```

### 第四步：配置服务端

再次进入「文件」页面，打开根目录下的 `server.properties`。

简幻欢在上一步启动服务端生成文件时，已自动修改 `server-ip` 为 `0.0.0.0`、`server-port` 为你实例分配到的端口号，因此这两个不用管。

如果你或你的朋友没有正版账户，请把 `online-mode` 的值由 `true` 改为 `false`。请注意，这样做会显著增加你的服务器遭受恶意攻击的风险！

更多关于服务器设置的配置请查看 [server.properties 详解](/docs/mcje/server_properties)。Mod 文件放入 `mods` 文件夹。

现在你已经配置好服务端了，去愉快地玩游戏吧！
