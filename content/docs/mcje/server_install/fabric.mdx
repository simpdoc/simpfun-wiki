## 图文教程（服务端专用安装器版）

### 第一步：安装服务端

前往 [Fabric 官网](https://fabricmc.net/use/installer/)，在下载页面选择红框内的 `Minecraft Server`：

![Fabric 官网下载页面中的 Minecraft Server 选项](/img/pages/mcje/mcje-fabric-2.webp)

在跳转到的新页面中选择 `MC 版本` 与 `Fabric Loader 版本`（Fabric Loader 默认选择最新版即可），然后点击下载：

![Fabric 安装器页面中选择 Minecraft 版本与加载器版本](/img/pages/mcje/mcje-fabric-3.webp)

下载完成后，将文件上传至实例文件的根目录。

打开根目录下的 `start.sh`，将启动服务器的命令改为下面的命令后保存（不要删除 `start.sh` 自带的东西，`echo` 那一行除外）：

```shell title="start.sh"
${openjdk21} -server -Xms1024M -Xmx${maxmem}M -jar <服务端文件名>.jar -nogui
```

<Callout type="info" title="提示">

`<服务端文件名>` 换成你下载到的安装器的文件名，例如 `fabric-server-mc.1.21.3-loader.0.16.9-launcher.1.0.1`：

![下载得到的 Fabric 服务端安装器文件名](/img/pages/mcje/mcje-fabric-4.webp)

</Callout>

此时的启动命令应如下图所示：

![start.sh 中修改后的 Fabric 启动命令](/img/pages/mcje/mcje-fabric-5.webp)

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk21}`：调用变量 `openjdk21`。请按下方的版本对照选择对应的变量，例如 1.16.5 应写成 `${openjdk8}`、1.20.4 应写成 `${openjdk17}`。
  + 1.14——1.16.5 需要 Java 8（部分版本的 mod 可能需要 Java 11 或 Java 16）
  + 1.17——1.20.4 需要 Java 17 或更高版本
  + 1.20.5——1.21.11 需要 Java 21 或更高版本
  + 26.1+ 需要 Java 25 或更高版本
+ `-server`：指示 JVM 在服务器环境中运行。这是一个优化标记，告诉 JVM 使用更适合长时间运行和高性能的配置。
+ `-Xms1024M`：服务器运行最小内存为 1024 MiB。`1024M` 可以修改：如果觉得最小运存太大，可以改为 `512M` 或其他值，只要数字部分是 4 的倍数；也可以写成 `1G`，效果相同。
+ `-Xmx${maxmem}M`：服务器运行最大内存为 `maxmem` M，`maxmem` 是上文定义的变量，值为服务器最大物理内存减 1000（单位 M）。**注意：`Xmx` 与 `Xms` 均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**
+ `-jar`：告诉 Java 要启动 jar 文件，此项不要更改或删除。
+ `<服务端文件名>.jar`：此处替换为你下载到的文件的名字。
+ `-nogui`：不启用 MC 服务端自带的 GUI 窗口，在面板服/命令行环境运行服务端时不能删。

</Callout>

保存后回到终端，启动服务器。服务端将会自动下载文件，请耐心等待一会。

当服务端正确下载完成后，服务器将直接启动。此时控制台上很可能会显示以下信息，之后服务器将停止运行：

```plain
[20:35:55] [main/WARN]: Failed to load eula.txt
[20:35:55] [main/INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

### 第二步：同意 EULA

转到「文件」页面，打开根目录下的 `eula.txt`。

```properties title="eula.txt"
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Sat Nov 18 21:32:42 CST 2023
eula=false
```

将其中的 `false` 改为 `true`。

<Callout type="error" title="警告">

将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

此外，若你需安装整合包，应在修改 EULA 后**不启动服务器**，待内容全部正确导入后再启动。

</Callout>

回到「终端」界面，点击右上角的「启动」，等待服务器首次运行。看到类似以下的提示即可关闭服务器：

```plain
[20:44:03] [Server thread/INFO]: Done (7.900s)! For help, type "help"
```

### 第三步：配置服务器

再次进入「文件」页面，打开根目录下的 `server.properties`。

简幻欢在上一步启动服务端生成文件时，已自动修改 `server-ip` 为 `0.0.0.0`、`server-port` 为你实例分配到的端口号，因此这两个不用管。

如果你或你的朋友没有正版账户，请把 `online-mode` 的值由 `true` 改为 `false`。请注意，这样做会显著增加你的服务器遭受恶意攻击的风险！

更多关于服务器设置的配置请查看 [server.properties 详解](/docs/mcje/server_properties)。Mod 文件放入 `mods` 文件夹。

现在你已经配置好服务端了，去愉快地玩游戏吧！

## 图文教程（通用安装器版）

### 第一步：安装服务端

前往 [Fabric 官网](https://fabricmc.net/use/installer/)，点击 `Download universal jar` 下载通用安装器。

![Fabric 官网中的 Download universal jar 按钮](/img/pages/mcje/mcje-fabric-6.webp)

下载完成后，将其上传至实例文件的根目录。

打开根目录下的 `start.sh`，在文件内添加一行下面的命令后保存（不要删除 `start.sh` 自带的东西，`echo` 那一行除外）：

```shell title="start.sh"
${openjdk17} -jar <安装器文件名>.jar server -mcversion <MC版本号> -downloadMinecraft
```

<Callout type="info" title="提示">

`<安装器文件名>` 换成你下载到的安装器的文件名，`<MC版本号>` 换成你需要的服务端版本（例如 `1.19.3`），两者都不要带尖括号。

</Callout>

例如，当安装器文件名为 `fabric-installer-1.0.1`、需要的服务端版本为 `1.20.1` 时，命令应如下图所示（第 14 行）：

![start.sh 中新增的 Fabric 通用安装器命令](/img/pages/mcje/mcje-fabric-7.webp)

保存后回到「终端」页面，启动服务器。此时安装器将会自动安装服务端核心并下载依赖文件，完成后服务器将会停止运行。

### 第二步：调整启动命令

打开根目录下的 `start.sh`（在 Windows 镜像下为 `start.cmd`），**先把第一步添加的那行命令删除**，然后再添加一行类似下面的命令后保存（不要删除文件里原本的东西，除了最下面那行 `echo`）：

```shell title="start.sh"
${openjdk17} -server -Xms1024M -Xmx${maxmem}M -jar fabric-server-launch.jar -nogui
```

<Callout type="info" title="关于各项参数的说明">

+ `${openjdk17}`：调用变量 `openjdk17`。请按下方的版本对照选择对应的变量，例如 1.16.5 应写成 `${openjdk8}`、1.20.5+ 应写成 `${openjdk21}`。
  + 1.14——1.16.5 需要 Java 8
  + 1.17——1.20.4 需要 Java 17 或更高版本
  + 1.20.5——1.21.11 需要 Java 21 或更高版本
  + 26.1+ 需要 Java 25 或更高版本
+ `-server`：指示 JVM 在服务器环境中运行。这是一个优化标记，告诉 JVM 使用更适合长时间运行和高性能的配置。
+ `-Xms1024M`：服务器运行最小内存为 1024 MiB。`1024M` 可以修改：如果觉得最小运存太大，可以改为 `512M` 或其他值，只要数字部分是 4 的倍数；也可以写成 `1G`，效果相同。
+ `-Xmx${maxmem}M`：服务器运行最大内存为 `maxmem` M，`maxmem` 是上文定义的变量，值为服务器最大物理内存减 1000（单位 M）。**注意：`Xmx` 与 `Xms` 均不要设为超出实例运行内存上限的值，也不要设反了让最大值比最小值小，会导致服务器无法启动！**
+ `-jar`：告诉 Java 要启动 jar 文件，此项不要更改或删除。
+ `fabric-server-launch.jar`：Fabric 构建器生成的启动 Fabric 服务端的文件，此项不要更改。
+ `-nogui`：不启用 MC 服务端自带的 GUI 窗口，在面板服/命令行环境运行服务端时不能删。

</Callout>

调整完的启动命令应类似下图所示：

![start.sh 中修改后的 Fabric 通用安装器启动命令](/img/pages/mcje/mcje-fabric-8.webp)

此时你可以删除 Fabric 安装器了。

### 第三步：同意 EULA

启动服务器，稍微等待一会后控制台会出现类似如下的提示并关闭服务器：

```plain
[21:32:42] [main/INFO] [minecraft/Main]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.
```

转到「文件」页面，打开根目录下的 `eula.txt`。

```properties title="eula.txt"
#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA).
#Sat Nov 18 21:32:42 CST 2023
eula=false
```

将其中的 `false` 改为 `true`。

<Callout type="error" title="警告">

将 eula 中的 `false` 改为 `true`，即视为你已阅读并同意 [《MINECRAFT 最终用户许可协议（EULA）》](https://www.minecraft.net/zh-hans/eula)！

</Callout>

回到「终端」界面，点击右上角的「启动」，等待服务器生成文件。看到类似以下的提示即可关闭服务端：

```plain
[21:33:52 INFO]: Done (38.223s)! For help, type "help"
```

### 第四步：配置服务器

再次进入「文件」页面，打开根目录下的 `server.properties`。

简幻欢在上一步启动服务端生成文件时，已自动修改 `server-ip` 为 `0.0.0.0`、`server-port` 为你实例分配到的端口号，因此这两个不用管。

更多关于服务器设置的配置请查看 [server.properties 详解](/docs/mcje/server_properties)。Mod 文件放入 `mods` 文件夹。

现在你已经配置好服务端了，去愉快地玩游戏吧！
