## 给予管理员权限
**打开控制台**

![服务器控制台界面](/img/pages/ins-console-2.webp)

**在输入栏中输入 **`op 玩家id`** 并执行**。

如果玩家 id 中包含空格或特殊字符，请使用引号将玩家 id 包裹起来，例如：

```text
op "玩家 id"
```

## 无法获取管理员权限？

可能的原因：
- 玩家不在线
- 控制台输入命令时带斜杠了
- 玩家 id 大小写不匹配

## 仍有问题？

已经确认玩家已被授予管理员权限，但仍然无法使用管理员命令？

请参阅此文档：[为服务器启用作弊](/docs/mcbe/common_operations/allow_cheat)
