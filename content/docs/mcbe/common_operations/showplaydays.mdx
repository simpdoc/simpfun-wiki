---
title: "启用游玩天数显示"
description: "使用命令或修改 server.properties 启用游玩天数显示。"
---


游玩天数显示是在 BE1.21 新加入的功能，那么如何在服务器中启用呢？

## 方法A：使用命令

![游戏世界设置中的游玩天数显示选项](/img/pages/mcbe/mcbe-showplaydays-1.webp)

在终端控制台输入以下命令（控制台内输入需要去掉斜杠）：

```shell
/gamerule showdaysplayed true
```

**注：需要**[启用作弊](/docs/mcbe/common_operations/allow_cheat)

## 方法B：修改配置文件

<Callout type="info" title="信息">

这段内容是隶属于[关于 server.properties](/docs/mcbe/server_properties)文档的。   
看完这段内容后想了解更多信息，请阅读父文档。

</Callout>

在 **server.properties** 中添加以下配置并重新启动服务器。

```properties
op-permission-level=4
```

如图所示：

![server.properties 中的 op-permission-level 配置](/img/pages/mcbe/bds-enable-command-block-2.webp)

然后在有OP权限的情况下游戏内的设置就可以更改了。
