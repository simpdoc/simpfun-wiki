## 操作步骤

### 安装镜像

[新建服务器](/docs/web/create_server) ，选择 `基础镜像` -> `自定义-需有开服经验` -> `AIO` ，或 重装服务器 ，选择 `基础镜像` -> `自定义-需有开服经验` -> `AIO` 。


### 修改启动参数

将 `start.sh` 中的启动命令修改为 `bash` ，正确的内容如图所示：

![start.sh 中修改后的 bash 启动命令](/img/pages/mcbe/xveib7sepf8z6qup-1.webp)


### 运行安装命令

启动服务器，根据 [快速开始 - LeviLamina Docs](https://lamina.levimc.org/zh/quickstart/) 中的安装命令（无需切换目录，一般安装命令为 `lipinstallgithub.com/LiteLDev/LeviLamina` ，如有变动请以官方教程为准），运行安装命令，安装完成界面如图所示：

![LeviLamina 安装完成后的终端输出](/img/pages/mcbe/xveib7sepf8z6qup-2.webp)
