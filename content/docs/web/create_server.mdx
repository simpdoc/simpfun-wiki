## 1.进入控制台

![点击官网的「进入控制台」](/img/pages/main-1.png)

## 2.进入实例页面

或者在主页的“快捷入口”中点击“创建实例”

![点击进入实例页面](/img/pages/console-2.webp)

## 3.点击创建实例

![创建实例](/img/pages/ins-1.png)

## 4.选择镜像类型

<Callout type="info" title="注意">

基础镜像：由 **简幻欢** 或 **部分作者** 维护的镜像（请注意，该镜像部分版本缺失！有需求可考虑使用第三方镜像）

第三方镜像: 由 **获批准的开发者** 维护的镜像（请注意，如需获取支持请优先向第三方开发者联系！）

</Callout>

![选择镜像类型](/img/pages/web/03-ins-create-1.png)

## 5.选择实例类别

<Callout type="info" title="注意">

+ Minecraft互通：基于 Minecraft JE 服务端 Paper 与互通插件 Geyser-Spigot 的 Minecraft JE 与 BE 互通服务器
+ MinecraftBE：Minecraft 基岩版
+ Terraria：泰拉瑞亚（现支持 Terraria 原版 / TModLoader / TShock）
+ 自定义：需要有一定的开服能力，**如果你是小白请勿轻易选择**！
+ MinecraftJE：Minecraft Java版
+ RustedWarfare：铁锈战争
+ Mindustry：像素工坊

</Callout>

![选择实例类型](/img/pages/web/03-ins-create-2.png)

## 6.选择实例服务端

以 MinecraftJE 为例

![选择服务端类型](/img/pages/web/03-ins-create-3.png)

## 7.选择镜像版本

以 Paper 为例，服务端因 自身问题 或 同步进度，所支持的版本不相同

![选择服务端版本](/img/pages/web/03-ins-create-4.png)

## 8.选择实例规格

<Callout type="success" title="提示">

实例命名方式为 [CPU级别.CPU厂商.具体配置.操作系统] 

+ CPU厂商以字母[A,I]分类，代表AMD,Intel。
+ 操作系统以字母L,W分类，代表实例操作系统Linux或Windows，可能会影响能使用的实例服务端。
+ 推荐在预算或内存足够的情况下，选择更高级别的CPU，以获得更流畅的体验，您也可以更换CPU厂商观察是否获得性能提升。
+ CPU级别以字母[C,B,A,S]等分级，代表具体CPU性能，详情型号等见[此官方文档](https://www.yuque.com/simpfun/sfe/areas)

</Callout>

![选择实例规格](/img/pages/web/03-ins-create-5.png)

<Callout type="warn" title="警告">

实例计费方式为按天付费，**当日不开服不扣积分**，创建当天须扣除当天所需费用

+ 当日开服指：服务器实例在当日24小时内启动过，无论是否是否进入服务器，服务器运行状态是否正常，只要启动即视为当日已开服。

磁盘可以超额，但超出套餐的磁盘将被额外计费，具体价格为：1积分/GB/天。

若当日开服所需积分不足，则会关闭实例，若连续7天未启动实例，则会 **销毁实例**，实例销毁前将会自动创建一个时限 60 天的备份，可随时在期限内通过新建实例->备份->还原功能恢复实例文件。

请注意，**过高**的实例规格可能会导致积分快速消耗，建议**按需**选用，后续仍可以更改配置。初次使用推荐从最小规格起步，若无法满足需求则可通过 **变配** 来改变实例配置。

初次使用高积分节点时，建议你观察高峰期时段的运行情况，若节点频繁禁止创建，建议暂不使用，否则可能导致 TPS 昼夜波动，或使用[简幻云](https://v2.simpcloud.cn/)来满足需求。

</Callout>

## 9.确认信息

检查信息无误后，点击 **立即创建** 后即可在实例页面查看您的服务器。

![确认信息](/img/pages/web/03-ins-create-6.png)
