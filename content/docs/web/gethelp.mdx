## 提问前的准备

### 您是否是有备而来呢？在提问前，您需要：

+ 尝试从已知信息，通过搜索引擎获取答案
+ 通过已有文档，教程来获取答案
+ 是否向您熟知的朋友获取答案

### 当您确实是找不到相关答案时，最好在提问时表明自己已尽力搜找答案，但依旧找不到结果，如：

+ 我从 XXX 引擎搜索，但都是无关内容
+ 我通过 xxx 的教程尝试了，但依旧无法解决问题


### 否则，没人知道您到底做了什么努力，只能认为您什么都没做，不求上进。
<Callout type="info" title="提示">

若有人只是给您丢了一个文档，抑或是其它链接之类，那证明大概率您没有认真查阅！

</Callout>
