title: "如何长期免费使用"
---

<Callout type="info" title="提示">

在 sfe4 中，简幻欢改良了签到方式，并适当添加了更多积分获取方式，使用户能够在充分了解简幻欢的前提下，轻松使用。

</Callout>

## 方式一：每日签到

前往微信小程序 【简幻欢】，点击签到，正确回答问题后，即可获得一定量积分，每日坚持签到，即可维护最基本的积分消耗。

若认为签到问题不合理，可前往疑难解答群 465468467 ，直接私聊管理询问，**请勿发至任何简幻欢官方群内，否则永久禁止加群处理**。

<Callout type="info" title="信息">

若签到界面未出现 【开始签到】 字样，可能是以下原因导致：
+ 账号自主注销后注册，同意注销后无法进入公益模式
+ 尝试注册小号，触发反恶意滥用机制
+ 账号开启了 Pro 模式，同意 Pro 模式将关闭公益模式，无法手动签到

</Callout>

## 方式二：在微信小程序【简幻欢】内观看广告

在微信小程序【简幻欢】内点击签到按钮，进行一系列操作后即可获得少量积分。每天最多可获得 30-31 积分。

![操作示意图](/img/pages/web/04-etu-1.webp)

<Callout type="info" title="提示">

以下情况下将无法观看广告：
+ 主动同意相关规则，开启 Pro 模式
+ 因开小号、账号借用等违反服务协议的行为，导致触发反滥用，自动开启 Pro 模式。
+ 因微信策略导致无法播放广告

</Callout>

## 方式三：向朋友推荐简幻欢

将简幻欢推荐给您的好友，好友注册时使用您的推荐码，成功认证后即可获得一定数量的积分，好友每次获得积分，您也会同时获得积分。

若宣传得当，可将好友作为无限造分🐔！

![推荐页面](/img/pages/web/04-etu-2.webp)

## 方式四：申请优质内容创作者激励计划

对于优质的内容创作者，简幻欢提供了申请通道，使创作者可以更好的创作内容。

申请方式： 微信小程序【简幻欢】 -> 用户管理 -> 激励计划申请

![激励计划申请](/img/pages/web/04-etu-3.webp)
