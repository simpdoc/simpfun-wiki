## 认证是实名吗？我的信息安全吗？

简幻欢高度依赖微信及其生态来验证，在此期间并不会收集您的敏感信息（如身份证号，实名等）

简幻欢只需您能够进行微信支付，即可证明您是具有资质获取公益权益的用户~

因此，务必妥善保管好您的微信号，因微信账号问题导致简幻欢使用受限，均不提供任何支持，需自行承担其后果。

当然，这并不意味着您可以进行 `开小号`，`请求他人代验证` 等滥用行为，简幻欢对这种恶意用户均有不同的措施，请自重。

## 是否支持换绑、解绑操作？

你悉知，已通过 [服务协议](https://www.yuque.com/simpfun/sfe/tos) 了解到 `注册时，须对注册信息的真实性、合法性、有效性承担全部责任，并配合简幻欢依法核验您的注册信息，且每个自然人仅允许拥有一个账号，不允许利用漏洞获取额外的权益，如开小号获得双份免费资源等` ，因此不支持任何换绑、解绑操作。此外任何试图绕过此限制的行为将触发反滥用机制，请试图违反用户协议的用户自重。

## 为什么现在签到积分只有 50？为什么需要回答问题？后面还会改吗？

经调查，50 积分正好可以长期使用 `C+.I.L.L` 和 `B+.I.L.L` 规格的实例，且满足大部分用户的需求。

同时，简幻欢提倡养成良好的查阅信息习惯，提倡您通过 `搜寻文档` 、 `使用搜索引擎` 等方式找到签到问题的答案，授人以鱼不如授人以渔，教您 `怎么做` 不如教您 `怎么搜`~

当然，签到问题并不会过难，简幻欢会通过统计签到问题的正确率，将正确率极低的问题重新评估并做出适当调整。如果您认为问题极难，那很可能**您并不适合本平台**。

如您认为签到问题不合理，请前往 QQ 群 [465468467](https://qm.qq.com/q/w2uDWm29I)，主动私聊管理员或群主，进行反馈！

同时，简幻欢也奉劝部分想要 **钻空子的人** 自重。

## 无法访问简幻欢/网站功能异常？

若您出现以下问题：

+ 终端不显示内容
+ 无法访问官网
+ 无法访问开设的服务器
+ ... ...

请根据以下流程排查：

1. 前往 [简幻欢状态监控](https://simp.host/status/simpfun) ，查看是否存在异常状态，若存在，我们将尽快处理，请耐心等待。
2. 尝试修改您的本地 DNS，推荐 `腾讯云公共 DNS` ，相关教程：[云解析 DNS 系统及设备接入 Public DNS 免费版说明](https://cloud.tencent.com/document/product/302/110786#e13e0d14-191a-4a75-943a-63a67bd4f3f2)
3. 检查本地是否使用代理类软件，若使用，请关闭后访问官网。
4. 排查其它问题（如自身维护不当导致程序崩溃、以错误的方式访问服务器、自身未做安全措施导致服务器被入侵等）。
