> 欢迎您加入简幻欢综合交流群。入群即视为您已阅读并同意遵守《简幻欢群规》（以下简称群规），本群规分为两部分请仔细阅读。若对群规条款存在任何异议，请立即退出本群。

## 一、宣传

每日仅可在所有交流群中的一个群宣传服务器，严禁群发，一日内多次宣传、多群宣传等，以避免过度推广行为。

## 二、禁止发布的内容

+ 垃圾广告
+ 违反相关法律法规 & 腾讯平台规定 & 简幻欢用户协议的行为：
  + [QQ 软件许可及服务协议](https://rule.tencent.com/rule/46a15f24-e42c-4cb6-a308-2347139b1201)
  + [简幻欢服务协议](https://www.yuque.com/simpfun/sfe/tos)
+ 其余公认的、违反群原则的信息，如刷屏、霸屏、发送口令红包、斗图、诱导点击、恶意利用机制、恶意引战等造成群聊氛围混乱的行为

## 三、禁止以下行为

+ 恶意使用模块/云端进行续火、抢红包行为等
+ 在群内搭建 QQ 机器人/邀请机器人
+ 任何滥用【简幻机器人】等群内机器人功能的行为
+ 群中询问签到答案、实例解锁答案的行为
+ 提问获取增值服务相关问题（如如何充值等）
+ 任何无脑提问的行为，如「如何进入服务器」、未按其它第三方软件说明提供日志且将此部分内容截图等

<Callout type="info" title="如何提问">

如何提问的完整说明见[获得帮助](/docs/web/gethelp)。

</Callout>

+ 原则上不得对他人进行误导，回答问题时应具备足够扎实的专业知识
+ 严禁通过任何方式、手段或工具，实施非正常获取或刷取活跃积分的行为

**处罚**：对于违反上述规定的用户，简幻欢及审核组将视情况对违规 QQ 账号实施「警告」「禁言」「禁止入群」等措施，但不影响使用简幻欢的基本功能。

## 四、清理不活跃群员

+ 每次清理不活跃成员前，管理组将提前在群内通知
+ 被清理的成员如有需要，可重新申请加入本群
+ 重新进群后，请勿询问「为什么踢我？」或类似问题，否则简幻欢审核组有权采取封禁处理

## 五、信息收集与使用

+ 为维护群聊秩序、处理违规行为及优化服务体验，简幻欢官方QQ群将在合法合规前提下，收集并记录群内公开聊天消息、QQ 账号及群昵称信息
+ 为保证服务质量，简幻欢官方交流群将会收集您的简幻欢账号uid，并核验QQ绑定，只有身份认证通过后，才可同意入群
+ 所收集信息仅用于群管理、违规核查、不活跃清理等内部管理用途，不会对外公开或用于其他商业目的
+ 如您继续在本群发言，即视为知悉并同意上述信息收集行为；若不同意，可选择退出本群
+ 信息保存将遵循最小必要原则，并在不再需要时予以删除

## 附则

本群群规的最终解释权归简幻欢与 QQ 所有，如有任何疑问或争议，将以简幻欢与 QQ 的解释为准。我们保留随时修改或更新群规的权利，以适应群的发展和变化。
