## 什么是自定义镜像
`自定义镜像` 是指只提供运行环境，技术细节均由**个人解决**的实例镜像，门槛较高。

服务器在创建后，根目录下只有一个`start.sh`(Linux)。

## 自定义镜像有哪些？
<Callout type="warn" title="警告">

镜像基于 Debian 12 ( 最新 LTS ) 开发

</Callout>

简幻欢 SFE4 新版本仅提供 1 种类型的自定义预设，它是：

+ `AIO (All In One)`
但这个镜像包括以下所有内容：
    - `Go` ( 1.24.2 )
    - `Java` ( ZuluJDK 8，11，16，17，19，21 )
    - `Net` ( 6，8，9 )
    - `Node` ( 22.14.0 ) + Yarn + PNPM
    - `Python` ( 3.9.22，3.10.17，3.12.10，3.13.3 )
    - `SteamCMD` ( Latest )
    - `Wine` ( 10 ) + Mono

<Callout type="warn" title="MC Java 版服务端应该使用哪个版本的 Java？">

1.7.10 —— 1.16.5 需要使用 Java 8 ；

1.17 —— 1.20.4 需要使用 Java 17 或更高版本；

1.20.5+ 需要使用 Java 21 或更高版本！

如果你使用的为模组端，那么部分 mod 可能对 Java 版本有特定要求。

[如何导入简幻欢没有的 Java 请点这里查看相关文档。](/docs/web/custom_image/addownjava)
