## 系统变量
| 变量名 | 变量含义 | 默认值 | 调用示例（bash） | 调用示例含义 |
| --- | --- | --- | --- | --- |
| SERVER_MEMORY | 服务器内存，单位 M | 以你目前使用实例规格为准 | maxmem=$((SERVER_MEMORY - 1000)) | 定义名为 maxmem 的变量，值为（服务器内存-1000）M |
| SERVER_PORT | 服务器主端口 | 以你目前使用实例规格为准 | sed -i "s/^server-port=.*/server-port=$SERVER_PORT/; t; a server-port=$SERVER_PORT" server.properties | 将服务器端口写进 server.properties 中 server-port 项 |
| TZ | 时区 | Asia/Shanghai | java -Duser.timezone=$TZ -jar your-app.jar | 启动 java 程序，使用 TZ 变量作为时区 |
