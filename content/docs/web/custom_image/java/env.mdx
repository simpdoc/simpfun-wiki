<Callout type="info" title="信息">

您是否遇到以下问题：

+ 垃圾程序插件必须使用环境变量 java
+ 想要偷懒直接使用一个命令

</Callout>

**本文档将教你如何在 Linux 使用环境变量！**

<Callout type="error" title="警告">

必须是非 root 才能运行的程序，且不可直接指向程序名，例如`export PATH="$PATH:/usr/bin/jdk/jdk-17.0.6/bin/java"`

</Callout>

## 修改启动参数
在启动脚本`start.sh`内添加一个`export PATH="$PATH:你需要的程序目录"`

<Callout type="warn" title="注意">

这个脚本必须置于主启动命令前（一般为最后一行命令），否则主启动命令使用环境变量时将可能出现问题。

</Callout>

![在 start.sh 中添加 export 示例](/img/pages/web/custom-java-env-1.png)

## 使用 bash 实验可用性（可选）
在`export`的下面添加一个 bash，并保存与启动服务器

您可以输入`java -version`来测试引用的 java 程序

测试完后将`bash`删除或在 bash 前面添加#，以便后续使用

<Callout type="info" title="信息">

如需了解更多 `export` 命令相关，可前往搜索引擎查阅更多教程！

</Callout>
