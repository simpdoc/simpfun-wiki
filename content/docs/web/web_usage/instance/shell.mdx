<Callout title="控制台 能干些什么？" type="info">

在 控制台 中，您可以对 实例 执行命令  
如 **开机** **关机** **重启** **强制关机** 这四种自带指令  
您也可以在 **命令框** 输入您想要执行的 **自定义命令** 并回车执行  
在该页面可以查看 实例 的基本信息，如 服务器IP、CPU、内存、网络流量等  

</Callout>

## 进入 控制台
在总览的实例列表或**实例管理**页面中，点击您想要管理的**实例**，即可进入控制台！
![实例管理页面](/img/pages/web/web_usage/instances.webp)
