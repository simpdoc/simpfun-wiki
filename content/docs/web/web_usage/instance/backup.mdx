<Callout title="镜像管理与回档管理的区别" type="warn">

镜像管理：主动创建镜像将消耗一定积分，保留 180 天，实例被销毁时，将创建一个长达 60 天的镜像，适合长期冷备份存储数据。  
回档管理：简幻欢将自动创建回档点，可选择一个回档点进行回档，适合误操作，遭到破坏时回档使用。

</Callout>
