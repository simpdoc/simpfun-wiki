<Callout type="info">

在首页中，点击`进入控制台`按钮后，即可进入控制台页面，其中包含您的用户名，积分，钻石，UID，实例信息，网站公告等：
![进入控制台](/img/pages/main-1.webp)

</Callout>

## 个人信息

您的个人信息在控制台主页显示，包含您的账号名，UID，积分数和钻石数
若您需要获得更多积分，可前往控制台，点击积分右侧的 ⊕ 按钮，点击查看详情。
![个人信息](/img/pages/web/web_usage/user-info.webp)

## 公告

当有新公告时，在您进入简幻欢官网后，会收到一个弹窗通知，同时您可以点击 公告 查看历史公告。
![公告](/img/pages/web/web_usage/announcements.webp)

## 实例

主页(或实例管理)中包含您所有建立的实例，即服务器。
![实例管理页面](/img/pages/web/web_usage/instances.webp)

## 帮助中心

可在此处获取相关帮助文档链接，同时可以绑定 QQ 号，绑定后可获取 QQ 交流群群号
![帮助中心](/img/pages/web/web_usage/help-center.webp)

## 设置

设置整个界面的使用体验
![设置](/img/pages/web/web_usage/settings.webp)

## 推荐

这里记录着因推荐获得的总积分，也记录着您的推荐码。
![推荐](/img/pages/web/web_usage/invite.webp)

## 积分记录

在这里，您可以查看所有积分/钻石记录，包括因何种原因变动积分/钻石，实例为何被销毁。
![积分记录](/img/pages/web/web_usage/history-points.webp)
