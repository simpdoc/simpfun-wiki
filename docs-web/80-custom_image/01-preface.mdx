# 【自定义镜像】前言

:::warning[警告]

+ 使用自定义镜像前，请确保你已经具备了一定的开服经验和英文阅读水平。
+ 如果你没有这方面的经验，请不要轻易尝试这部分的内容！
:::

## 什么是自定义镜像？
自定义镜像，是指 **只提供运行环境，技术细节均由个人解决 **的实例镜像，门槛较高。

服务器在创建后，根目录下只有一个 `start.sh` 。

## 我该何时使用自定义镜像？
:::danger[警告]

在简幻欢，我们专注于提供游戏服务器的支持和服务。请注意，我们的平台仅适用于游戏服务器的搭建，若发现在此建立其他服务（如网站，网盘等），简幻欢将关闭您的服务器并 **永久封禁** 您的账户。
:::

若有以下需求，强烈建议使用自定义镜像：

+ 官方镜像或第三方镜像没有需要的预设，需要自行安装部署；
+ 有更高需求，需额外安装环境或使用更复杂的命令实现等。

## 自定义镜像有哪些？
:::info[信息]

如果页面显示了 Ubuntu 和 Windows，并不是简幻欢提供的自定义镜像，而是简幻欢投放的广告。
:::

当前自定义镜像有两种：

+ Java 镜像：提供多个版本 Java 和部分实用环境变量的镜像。
+ AIO 镜像：集成多种运行环境的全量镜像。

区别如下表：

|  | AIO 镜像 | Java 镜像 |
| :---: | :---: | :---: |
| （仅 Minecraft）自动配置端口 | 不支持 | 支持 |
| 更多环境支持 | 支持大量环境 | 以 Java 环境为主 |
| 上手难度 | 较高 | 较低 |
| 使用建议 | 游戏服务端需要额外环境、或游戏服务器需要 Windows 系统等复杂需求 | 只想简单部署 mc 整合包、一些基于 Java 开发的游戏服务端等简单需求 |
