## 参与贡献

我们欢迎任何形式的贡献——**你不需要会写代码**，改文档同样是最重要的贡献。

- **想补充或修正文档内容？** 请先阅读 [贡献指南](CONTRIBUTING.md)，其中列出了三套文档各自对应的目录与新增页面的步骤。
- **想改站点配置、构建或部署？** 请阅读 [开发与构建文档](development.md)。
- **发现了错误但没时间改？** 直接[新建 Issue](https://github.com/simpdoc/simpfun-wiki/issues/new/choose) 也很有帮助——我们有「文档内容建议」「文档错误提交」「其他内容」三种模板可选。
- **不确定怎么写？** 欢迎先来[讨论区](https://github.com/simpdoc/simpfun-wiki/discussions)聊聊。

最简单的起步方式：直接点开任意文档页面底部的 **「编辑此页」**，在 GitHub 上改完提 PR 即可。
