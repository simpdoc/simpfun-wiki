## 参与贡献

我们欢迎任何形式的贡献——**你不需要会写代码**，改文档同样是最重要的贡献。

- **想补充或修正文档内容？** 请先阅读 [贡献指南](CONTRIBUTING.md)，其中列出了三套文档各自对应的目录、写作规范与新增页面的步骤。
- **想改站点配置、构建或部署？** 请阅读 [开发与构建文档](DEVELOPMENT.md)。
- **发现了错误但没时间改？** 直接[新建 Issue](https://github.com/simpdoc/simpfun-wiki/issues/new/choose) 也很有帮助。
- **不确定怎么写？** 欢迎先来[讨论区](https://github.com/simpdoc/simpfun-wiki/discussions)聊聊。

最简单的起步方式：打开任意文档页面，点击标题下方的 **「打开」→「在 GitHub 中打开」**，在 GitHub 上改完提交 PR 即可，全程不需要本地环境。
